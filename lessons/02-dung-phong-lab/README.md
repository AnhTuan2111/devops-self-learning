# Bài 02 — Dựng phòng lab: WSL2 Ubuntu + Docker Desktop

> **Module M0** · Nền tảng — Server và Internet thực sự là gì
> Ước lượng: ~45 phút · Trạng thái: `todo`

## Mục tiêu

Có một môi trường Linux thật trên chính máy Windows để thực hành cả lộ trình mà không tốn tiền VPS.

## Khái niệm sẽ gặp

- WSL2 là gì
- Ubuntu filesystem vs Windows filesystem
- Terminal, shell, bash
- Docker Desktop + WSL backend
- Cách không làm hỏng máy

## Bài lab

Khởi động Ubuntu, tạo user, cập nhật hệ thống, kiểm tra docker chạy được trong WSL, tạo thư mục lab.

## Tự kiểm tra

Học xong phải tự làm được, không nhìn tài liệu:

- [ ] Mở được terminal Ubuntu và biết mình đang đứng ở đâu
- [ ] Chạy được `docker run hello-world` từ trong WSL
- [ ] Biết đường dẫn qua lại giữa Windows và WSL
