# Bài 03 — Filesystem và điều hướng: bản đồ của một máy Linux

> **Module M1** · Linux — Điều khiển một server
> Ước lượng: ~40 phút · Trạng thái: `todo`

## Mục tiêu

Đi lại trong một server lạ mà không bị lạc, và biết cái mình cần nằm ở thư mục nào.

## Khái niệm sẽ gặp

- Cây thư mục gốc /
- /etc /var /usr /home /opt /tmp /proc
- Đường dẫn tuyệt đối vs tương đối
- pwd ls cd tree
- Hidden file

## Bài lab

Đi một vòng qua từng thư mục hệ thống và trả lời: thư mục này chứa gì, vì sao nó tồn tại.
