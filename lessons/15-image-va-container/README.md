# Bài 15 — Image và Container: vòng đời đầy đủ

> **Module M3** · Docker — Đóng gói ứng dụng
> Ước lượng: ~50 phút · Trạng thái: `todo`

## Mục tiêu

Thành thạo thao tác hằng ngày với container mà không cần tra lệnh.

## Khái niệm sẽ gặp

- Image vs Container (class vs object)
- run, ps, logs, exec, stop, start, rm, rmi
- Tag và registry
- Docker Hub
- -d, -it, --rm, --name
- Restart policy

## Bài lab

Chạy PostgreSQL bằng container, exec vào trong, tạo bảng, thoát ra, xóa container, quan sát mất dữ liệu.
