Chưa học

Trang này mới chỉ là khung bài. Nội dung đầy đủ — giải thích, sơ đồ, bảng tra và phần mổ băng lab — sẽ được viết vào đúng buổi học bài này.

Mục tiêu

Vẽ được pipeline mình cần TRƯỚC khi viết dòng YAML nào.

Khái niệm sẽ gặp

  • CI vs CD vs Continuous Deployment
  • Build → Test → Package → Deploy
  • Artifact và registry
  • Environment: dev/staging/prod
  • Trunk-based vs Git flow
  • Vì sao pipeline chậm thì vô dụng

Bài lab

  • Có sơ đồ pipeline cụ thể cho project của mình
  • Phân biệt rõ CI và CD
  • Biết bước nào bắt buộc phải có người duyệt
