# Bài 31 — GitHub Actions cơ bản — và deploy chính website học tập này

> **Module M6** · CI/CD — Tự động hóa toàn bộ
> Ước lượng: ~60 phút · Trạng thái: `todo`

## Mục tiêu

Pipeline đầu tiên trong đời: mỗi lần push, trang tài liệu học tập của bạn tự động lên mạng.

## Khái niệm sẽ gặp

- workflow, job, step, action
- runner
- on: push / pull_request / workflow_dispatch
- Ma trận (matrix)
- Đọc log của một run
- GitHub Pages deploy action

## Bài lab

Viết workflow tự động deploy thư mục này lên GitHub Pages mỗi khi push lên main.

## Tự kiểm tra

Học xong phải tự làm được, không nhìn tài liệu:

- [ ] Push code → vài phút sau trang web tự cập nhật
- [ ] Đọc và hiểu được toàn bộ file YAML mình viết
- [ ] Debug được khi workflow đỏ
