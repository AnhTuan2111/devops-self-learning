# Bài 01 — Máy tính, Hệ điều hành, Process: 'server' thật ra là cái gì

> **Module M0** · Nền tảng — Server và Internet thực sự là gì
> Ước lượng: ~45 phút · Trạng thái: `todo`

## Mục tiêu

Hiểu server chỉ là một máy tính chạy 24/7, và mọi thứ bạn deploy cuối cùng đều là một process đang chạy.

## Khái niệm sẽ gặp

- CPU / RAM / Disk
- Kernel & user space
- Process, PID, thread
- File descriptor
- Filesystem
- Vì sao app chết thì website sập

## Bài lab

Quan sát process của chính Spring Boot / Node trên máy mình. Tìm PID, xem RAM, kill nó, xem điều gì xảy ra.

## Tự kiểm tra

Học xong phải tự làm được, không nhìn tài liệu:

- [ ] Chỉ ra được process nào đang giữ một port
- [ ] Giải thích được OOM (hết RAM) sẽ làm gì với app
- [ ] Phân biệt process và service
