# Bài 26 — Deploy thủ công lần đầu: cảm nhận nỗi đau

> **Module M5** · Production — VPS thật, domain thật, HTTPS thật
> Ước lượng: ~70 phút · Trạng thái: `todo`

## Mục tiêu

Tự tay deploy một lần, để hiểu CI/CD sau này đang tự động hóa CÁI GÌ.

## Khái niệm sẽ gặp

- Đưa code/image lên server
- Cấu trúc thư mục deploy
- Chạy compose trên production
- Log ở đâu, debug thế nào
- Ghi lại từng bước để sau này script hóa

## Bài lab

Deploy stack lên VPS bằng tay, truy cập bằng IP. Ghi lại CHÍNH XÁC từng lệnh đã gõ.

## Tự kiểm tra

Học xong phải tự làm được, không nhìn tài liệu:

- [ ] Truy cập được ứng dụng qua IP public
- [ ] Có một file runbook liệt kê mọi bước
- [ ] Chỉ ra được ít nhất 3 bước dễ sai nếu làm thủ công
